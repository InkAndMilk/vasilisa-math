# Математическая экспедиция Василисы 2.4 — публичная сборка

В этот каталог входят **только зашифрованная игра и открытые художественные файлы**. Исходный `index.html` сюда не попадает.

## Публикация на GitHub Pages

1. Размещайте содержимое этой папки **в корне** публичного репозитория `vasilisa-math`.
2. В GitHub → Settings → Pages включите публикацию из ветки main, папка `/ (root)`.
3. После публикации используйте HTTPS-ссылку, например `https://<owner>.github.io/vasilisa-math/`.
4. На iPhone: открыть ссылку через Safari → Поделиться → На экран «Домой».
5. Пароль сообщайте родственникам отдельно от ссылки.

**Не загружайте исходники из приватной папки в публичный GitHub.** Artwork-файлы сами по себе доступны по адресам `stickers/*.png`; это нормально для статического PWA. Зашифрован только код игры.

Прогресс каждого устройства сохраняется в браузерном хранилище и не синхронизируется автоматически. Сделайте резервную копию в родительском разделе перед крупными обновлениями или переносом устройства.
